.# Superstore Sales Dashboard

## Project Overview
This project analyzes Superstore sales data using Power BI. The dashboard provides insights into sales performance, profit trends, customer segments, and regional performance.

## Tools Used
- Power BI
- Data Visualization
- Data Cleaning
- Interactive Dashboard

## Key Insights
- Total Sales Analysis
- Profit Analysis
- Category-wise Performance
- Sub-Category Analysis
- Region-wise Sales Trends
- Customer Segment Analysis

## Dashboard Features
- Interactive Filters
- Sales and Profit Tracking
- Regional Performance Analysis
- Visual Reports and Charts

## Files Included
- Superstore Sales Dashboard.pbix
- Superstore Dataset
- Dashboard Screenshots

## Conclusion
The dashboard helps identify top-performing categories, profitable regions, and sales trends to support business decision-making.
